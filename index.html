📖 README

Text Editor

📅 Date/Time — inserts current date & time at cursor.

💾 Export — saves editor text as a .txt file.

Clear — empties the editor.

Copy — copies all editor text to clipboard.

Separator

Choose Space or New Line — controls how items are joined when added to the editor.

Timestamp on Select

When On (default), any action that copies an item — the list's Select button, double-tap "Copy Only," double-tap "Copy + Paste," and saving an edited item — stamps the current date/time before it, joined with your chosen separator. Turn Off to copy just the item text. (Double-tap "Select" just highlights the item and doesn't copy anything by itself.)

Backup & Restore

💾 Download — saves all your lists as a .json file.

📁 Restore — loads lists from a previously saved .json file.

Pick Lists

Tap the list title to rename it.

▲ ▼ (next to Select) — reorders the whole list up/down.

Select — copies the highlighted item and adds it to the editor.

+ — add a new item. 🗑 — delete the entire list.

Items

Tap an item to select (highlight) it.

Double-tap an item — runs your chosen double-tap action (see ⚙️ menu).

✏️ — edit the item. × — delete the item.

▲ ▼ (on item) — moves that single item up/down in the list.

Other

↑ ↓ floating buttons — jump to top/bottom of the page.

Your data auto-saves on this device. Use Download/Restore to move data between devices.
